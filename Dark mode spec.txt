Для веб версії (буде 1.5.0) реалізуєм можливість перемикатися на темну/світлу тему. По дефолту тема світла (як зараз)

загальний фон поза вікна #F3F3F3 = #080808
вікно #FFFFFF = #292929
рамки/межи полів та кнопок #C8C8C8 = #5e4c09
фон полів вводу, комірок Value = #5a5a5a
фон комірок key = #505050
скролл бар та кнопки скролу #636363 = #705a0b
Назви Paste cURL (bash) type from DevTools, Converted URL, Request, Requests params, Response, Time: ХХХ ms, Size: 105 B, v1.3.0 · web edition = #b89412
Текст в полях, Key, Value   = #94770e
тіні які є зараз у світлій темі стабілізуємо відносно темних кольорів що я вказав.

Колір кнопок, виділення параметрів, наприклад POST,application/x-www-form-urlencoded, Status code: XXX лишаєм як зараз.

Перемикання режиму темний/світлий кнопкою. 
Для веб версії кнопка розташована ліворуч від інформації про версію (наприклад, v1.3.0 · web edition) по вертикалі вирівняно однаково с текстом.
Кнопка виглядає як прямокутник з скуленими кутами (як для Status code: ХХХ). 

Для перемикання у темну тему прямокутник залитий кольором #292929, в середині надпис "Dark mode" кольору #b89412
Висота кнопки та розмір шрифту як шрифт та виділення для Status code: ХХХ

Для перемикання у світлу тему прямокутник залитий кольором #F5F5F5, в середині надпис "Light mode" кольору #292929
Висота кнопки та розмір шрифту як шрифт та виділення для Status code: ХХХ
